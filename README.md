# Stroke Prediction using Artificial Neural Network

A machine learning web application that predicts stroke risk using an Artificial Neural Network (ANN).

## Project Overview

This project uses healthcare data to build a binary classification model for stroke prediction.

The complete workflow includes:

- Data preprocessing
- Handling missing BMI values
- Categorical feature encoding
- Feature scaling
- Handling class imbalance using class weights
- Artificial Neural Network development using TensorFlow/Keras
- Model evaluation
- Streamlit frontend
- Model deployment-ready structure

## Technologies Used

- Python
- TensorFlow
- Keras
- Scikit-learn
- Pandas
- NumPy
- Streamlit
- Joblib

## Dataset

The project uses the Healthcare Stroke Dataset containing patient information such as:

- Gender
- Age
- Hypertension
- Heart disease
- Ever married
- Work type
- Residence type
- Average glucose level
- BMI
- Smoking status

The target variable is:

- `stroke`

where:

- `0` = No stroke
- `1` = Stroke

## Model

The project uses an Artificial Neural Network with the following architecture:

- Input layer
- Dense layer with 32 neurons and ReLU activation
- Dropout layer
- Dense layer with 16 neurons and ReLU activation
- Dropout layer
- Output layer with sigmoid activation

The model is trained using:

- Adam optimizer
- Binary cross-entropy loss
- Class weights for handling class imbalance

## Saved Model Files

The trained model and preprocessing components are saved separately:

- `model.keras` - trained ANN model
- `scaler.pkl` - StandardScaler used for numerical features
- `feature_columns.pkl` - feature names and their order used during training

Keeping the feature column order is important because the frontend must provide input to the ANN in exactly the same structure as the training data.

## Running the Project

Clone the repository:

git clone https://github.com/burhan-arshad/healthcare-stroke-prediction

Move into the project directory:

cd healthcare-stroke-prediction

Create and activate a virtual environment if required:

python -m venv .venv

Windows:

.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run app.py

The application will open in the browser.
